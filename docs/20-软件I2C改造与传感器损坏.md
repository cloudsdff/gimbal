## 一、今天最重要的发现：硬件 I2C 会锁死

### 现象链

```
① 舵机来回动作 10 秒
② I2C 开始报错
③ 采样率从 100 Hz 掉到 12 Hz
④ 从此永久失效，MCU 复位也恢复不了
⑤ 拔掉从机线，I2C 外设的 BUSY 位依然是 1
```

第 ⑤ 条是关键证据：**卡死的是 MCU 自己的 I2C 外设状态机，不是从机**。

### 为什么恢复流程救不回来

F103 的 I2C1 是出了名的难伺候：

| 尝试 | 结果 |
|---|---|
| 9 个时钟 + STOP | 只能解决"从机拉低 SDA"，解决不了外设内部状态 |
| CR1.SWRST 软复位 | 有时能救，但外设已锁死时写不进去 |
| DeInit + 重新 Init | 同上 |
| 降低速率到 50 kHz / 25 kHz | 延缓，但不能根治 |

### 解决方案：软件模拟 I2C（bit-bang）

不再使用 I2C1 外设，直接用 GPIO 控制 PB6/PB7 电平：

```c
// 起始条件
SDA 高 → SCL 高 → SDA 低 → SCL 低

// 写字节
8 位数据 → 第 9 个时钟读 ACK

// 读字节
释放 SDA → 8 个时钟读 → 主机回 ACK/NACK
```

**为什么这样就不锁死**：bit-bang 没有"外设状态机"这个概念，
每根线就是一个 GPIO 输出寄存器。读失败最多是返回 NACK，
下一次起始条件又是干净的。

### 实测对比

| 指标 | 硬件 I2C | 软件 I2C |
|---|---|---|
| 静态采样率 | 100 Hz | 100 Hz |
| 舵机扫 10 秒后 | **12 Hz 且永久失效** | **98 Hz，自动恢复** |
| 恢复方式 | 必须断电重启传感器 | 无需操作 |

**这就是今天最有价值的成果**：一个能自动恢复的传感器链路。

## 二、顺带修掉的两个控制 bug

### 2.1 积分限幅用了输出限幅

```c
// 错误：积分限幅 = 输出限幅 = 35°
st.integ = clampf(st.integ, -35, 35);

// 正确：积分只该消除静态偏差，不需要占满输出范围
st.integ = clampf(st.integ, -5, 5);
```

**现象**：平台被顶在机械下限不动，因为积分一直停在 -35°，
即使误差反向也拉不回来（要把积分从 -35 涨回 0 需要很久）。

**修复**：积分独立限幅 ±5°，并在 `resume()` / `set_enabled(true)` 时清零。

### 2.2 校准因振动丢弃全部采样

```c
// 错误：角速度超阈值就清零重来
if (rate_mag > 20) {
  cal_sum_x_ = cal_sum_y_ = cal_sum_z_ = 0;
  cal_count_ = 0;
  return Busy;
}

// 正确：振动是零均值的，直接求平均就是零偏估计
if (rate_mag > 20) { ++cal_rejected_; }   // 只统计，不丢弃
```

**现象链**：

```
闭环一开始 → 舵机持续微调 → 平台有振动
→ 校准永远凑不满 200 帧
→ 陀螺零偏没被扣掉
→ -8 dps 积分 10 秒 = 漂 80°
→ 姿态发散到 -86°，看起来像"闭环振荡"
```

这是最容易误判的一类 bug：**现象在控制器，根因在标定**。

## 三、最终卡住的地方：MPU6050 损坏

### 证据

用 J-Link 直接读 GPIO 寄存器，排除了软件问题：

```
CRL  = 0x66484444   → PB6/PB7 = 0x6（开漏输出 2MHz）✅ 配置正确
IDR  = 0x000000D0   → PB6(SCL)=1  PB7(SDA)=1        ✅ 总线空闲为高
```

引脚配置对、总线空闲正常，但从机在 0x68 和 0x69 两个地址都不应答，
模块电源 LED 却是亮的。

**判定：芯片的 I2C 接口损坏**（有电、但不再响应总线）。

### 损坏原因推测

```
今天经历：插拔 10+ 次、上电/断电 12+ 次
         长时间被舵机 PWM 与电流突变干扰
         两次读到全 0 / 全 -1 / 0x7FFF 饱和
```

廉价 GY-521 模块（无 TVS、无隔离）在这种环境下损坏是常见结果。

### 处理

已下单 3 块 GY-521（含任务04 用量）。到货后：

```
① 换上新模块
② 跑 docs/20-闭环调参脚本（已准备好）
③ 补测指标：静态抖动、阶跃、重复精度
```

## 五、给后续的经验

1. **传感器链路要有"能自动恢复"的设计**，不能依赖外设状态机
2. **现象在控制器、根因在标定**——先确认姿态数据可信，再调增益
3. **积分限幅必须独立于输出限幅**，否则一次饱和就再也拉不回来
4. **调试用的硬件要有备份**，10 块钱的模块能省一天时间
