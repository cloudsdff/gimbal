# 任务02 · 完整接线方案

> 平台：STM32F103C8T6（蓝药丸）· MPU6050 · SG90 ×2（二轴云台）· BLE 透传模块 · DCP3512 电源模块
> 日期：2026-11-23

---

## 一、总览：三套电，一个地

```
                    ┌─────────────────┐
   220V ──→ 12V 适配器 ──→│ DCP3512 四路电源 │
                    │  12V 输入        │
                    │  5V 输出 ────────┼──→ 舵机 ×2 红线（并联）
                    │  GND ────────────┼──┐
                    └─────────────────┘  │
                                          │
   电脑 USB ──→ 蓝药丸 micro USB ──→ 板上 LDO ──→ 3.3V ──→ MPU6050 VCC
                     │  5V 引脚 ──────────────┼──→ BLE 模块 VCC
                     │  GND ──────────────────┴──→ 所有 GND 汇合点
                     │
                     ├── J-Link（只 SWD 三根）
                     └── CH340（只串口三根）
```

**三套电源各自独立、只用 GND 连在一起**：

| 电源 | 供谁 | 电压 |
|---|---|---|
| 12V 适配器 → DCP3512 | 舵机（大电流） | 5V |
| 电脑 USB → 板子 | MCU + MPU6050 + BLE | 5V / 3.3V |
| 电脑 USB → J-Link / CH340 | 调试 | — |

> **为什么舵机不共用板子的 5V**：两个 SG90 峰值 1.5 A，板子的 USB 供不起，
> 一旦掉压，MCU 会复位、BLE 会断连——看起来像三个不同 bug，其实是同一个电源问题。

## 五、共地：最容易漏的一步

```
必须连在一起的 GND：
  DCP3512 GND
  蓝药丸 GND
  两个舵机棕线
  MPU6050 GND
  BLE 模块 GND
  CH340 GND
  J-Link GND
```

**为什么必须共地**：所有信号电压都是相对 GND 测量的。如果两块电路 GND 不连，
信号电平就没有共同参考，接收端会读到随机值——表现为"数据全是乱码"或"时好时坏"。

**检查方法**：万用表通断档，两只表笔分别点两处 GND，应响。

## 六、上电顺序

```
第 1 步：接好 12V → DCP3512，量 5V 输出正常
第 2 步：接好所有信号线与 GND
第 3 步：插板子 USB（此时 5V 引脚有电，BLE 点亮）
第 4 步：保持云台静止 2 秒（正在自校准）
第 5 步：舵机归中动一下 → 校准完成
第 6 步：打开串口（COM3 @115200）看日志
```

**串口正常输出应该是**：

```
[I] bluetooth init -> Ok
[I] mpu6050: WHO_AM_I=0x68 ok
[I] pwm: TIM3 CH1/CH2 @50Hz ready (PA6/PA7)
[I] servo ch1 init at 900(0.1deg) 1500 us
[I] servo ch2 init at 900(0.1deg) 1500 us
[I] gimbal init: center=900(0.1deg) kp=200 kd=60 ki=50
[I] calibrating 200 samples (keep still)...
[I] calib done: gyro bias = [...]
[I] att 200Hz samp=... rx=0 bt=0 | yaw=0 pitch=0 roll=0 servo=1500/1500
```

最后一行 `servo=1500/1500` 是关键：**两个舵机都在中位**。

## 七、常见错误对照

| 现象 | 原因 | 处理 |
|---|---|---|
| 串口无输出 | CH340 TX/RX 接反 | 两根线交换 |
| 串口全是乱码 | 波特率不对 / 没共地 | 检查 115200 和 GND |
| `mpu init -> NoAck` | MPU6050 没接好 / 接了 5V | 检查 3.3V、B6、B7 |
| 舵机不动 | 信号线没接 / 没独立 5V | 量舵机红线 5V |
| 舵机一直抖 | 电源掉压 | 量带载 5V，<4.6V 要换电源 |
| 舵机往一边转到底 | 方向反了 | 发 `S,-1,1` 或 `S,1,-1` |
| 板子反复复位 | 舵机和板子共用 5V | 分开供电 |
| BLE 收不到 | 波特率不匹配（应为 38400） | 调试口发 `B,38400` |
| 烧录失败 | J-Link 3V3 和 USB 顶电 | 拔掉 J-Link 的 3V3 |

## 九、验证动作（接完线做这三步）

### ① 姿态验证

```
把平台前后点头 → 串口 pitch 变化
把平台左右侧倾 → 串口 roll 变化
```

### ② 单轴动作验证（用调试串口发）

```
T,3000,0    → 只有 Yaw 转（+30°）
T,0,0       → 回中位
T,0,3000    → 只有 Pitch 转（+30°）
T,0,0       → 回中位
```

### ③ 闭环验证

```
发 T,0,0 后，用手轻轻转动底座
→ 上层平台应保持指向不变（反向补偿）
→ 如果跟着同向转（越转越歪），发 S,-1,1 取反
```
