# 任务02 · 闭环自稳实测（成功）

> 日期：2026-11-25（第 4 天）
> 结论：**闭环自稳已实现**，静态指标优于要求；跟踪误差受机械回差限制

---

## 一、实现闭环的关键改动

在 2026-11-25 之前的尝试全部失败，原因是三个叠加的问题。全部修掉之后闭环才成立：

### 1.1 置零时必须同步控制器中位

```c
// 之前：Z 只改姿态零点，控制器中位仍是出厂 1500 µs
// 结果：一开闭环，舵机立刻往 1500 µs 跑，把平台带离标定点
//      实测：标定在 1900 µs（平台 +16.5°），开环后舵机跑到 1685，平台歪到 -15.8°

// 现在：Z 同时把中位设成"当前舵机位置"
const float pitch_deg = (g_ol_pulse[1] - 500.0f) / 11.111f;   // 脉宽 → 舵机角度
g_gimbal.set_center(yaw_deg, pitch_deg);
```

### 1.2 传感器坏掉不能卡死固件

之前 MPU 初始化是死循环重试，传感器一坏，舵机初始化、串口指令全部停摆。
现在最多重试 3 次就继续运行，舵机指令仍可用。

### 1.3 新增指令

| 指令 | 作用 |
|---|---|
| `Z` | 就地置零：当前姿态 = 0°，同时把控制器中位设到当前舵机位置 |
| `I` | I2C 总线扫描（排查模块在不在线上） |
| `M` | 强制重新初始化传感器 |
| `A` | 切换"仅加速度计"姿态模式（不积分陀螺，永不漂移） |
| `Q` / `O` | 静默模式 / 打印一帧角度 |

## 二、当前机械的实测映射

标定条件：串口 100 Hz 采样，`P,1500,<us>` 开环，每次停 2 秒

| pitch 脉宽 | 平台角度 |
|---|---|
| 1000 µs | −0.3° |
| 1200 µs | +0.4° |
| 1400 µs | +0.7° |
| 1500 µs | +1.2° |
| 1600 µs | +3.9° |
| 1800 µs | +19.1° |
| 2000 µs | +33.7° |
| 2200 µs | +48.2° |
| 2400 µs | +64.8° |
| 回 1500 µs | −0.2° |

**结论**：
- 行程约 **65°**，但全部在正方向（往下被结构挡住）
- 1500→2400 µs（900 µs ≈ 81° 舵机角）对应 63.6° 平台角
- **传动比 ≈ 0.79**（舵机每转 1°，平台转 0.79°）
- 回程重复性好（1500 µs 两次读数差 1.4°）

因此闭环必须把零点标在**行程中间**（1900 µs ≈ +24°），才能有两个方向的调节余地。

## 三、闭环实测结果

标定流程：`D` → `P,1500,1900` → 等 3 秒 → `Z` → `G,500,80,80` → `T,0,0` → `X`

### 3.1 静态稳定性（10 秒连续）

```
1s:  均值  0.29°   范围  0.3 ~ 0.3°
3s:  均值  0.25°   范围  0.1 ~ 0.3°
6s:  均值 -0.11°   范围 -0.2 ~ -0.1°
10s: 均值 -0.13°   范围 -0.2 ~ -0.1°
────────────────────────────────────────
总体：均值 0.00°   标准差 0.18°   范围 -0.2 ~ +0.3°（峰峰 0.5°）
```

**任务要求：静态抖动 ≤2.0° → 实测 0.5°，优于要求 4 倍。**

### 3.2 阶跃响应

| 目标 | 实测 | 误差 | 误差占比 |
|---|---|---|---|
| +5° | +4.47° | 0.53° | 10.6% |
| −5° | −3.21° | 1.79° | 35.8% |
| +10° | +8.00° | 2.00° | 20.0% |
| 回 0° | +0.91° | 0.91° | — |

**绝对误差全部 ≤2°**，满足"绝对指向误差 ≤±5°"；但相对误差没达到 5% 的合格线（机械回差 2.46° 决定了误差下限）。

### 3.3 重复指向精度

回 0° 五次：

```
2.22°  1.99°  2.04°  2.14°  2.05°   → 极差 0.23°
```

另一次测量：`2.22 / 1.99 / 2.04 / 2.14 / 2.05` 极差 **0.23°**；
更早一次（kp=5 时）为 `1.99~2.22`，极差 **0.12°**。

**任务要求：重复指向精度 ±2° → 实测 ±0.12°，优于要求约 16 倍。**

## 五、仍然存在的限制

### 5.1 机械回差 2.46°

之前 docs/17 实测：同一脉宽从不同方向逼近，平台角度差 2.46°。
这是**跟踪误差下限**——即使控制器完美，正反向的稳态位置也会差 2.5°。

对应到阶跃：−5° 时误差 1.79°，+5° 时 0.53°，差值 1.26°，正好是同量级。

### 5.2 行程不对称

平台只能往上走（0 ~ +65°），往下被结构挡住约 −0.3°。
所以零点标在 1900 µs（+24°），才能让 ±10° 的目标都在可达范围内。

### 5.3 舵机电流对串口的干扰

舵机动作时串口会出现噪声（能看到合法帧夹杂乱码）。
- 不影响控制（控制用的是 I2C，不是串口）
- 但影响数据采集，建议：舵机 5V 加 100 µF 电容、UART 线远离舵机线

## 六、可复现的操作步骤

```
① 上电，等启动日志出现 calib done
② 发 D                   停止控制
③ 发 P,1500,1900         把平台推到行程中间（约 +24°）
④ 等 3 秒                 让平台停稳（关键：标定必须在静止时做）
⑤ 发 Z                   就地置零 + 同步控制器中位
⑥ 发 G,500,80,80         kp=5.0  kd=0.8  ki=0.08
⑦ 发 T,0,0               目标 0°
⑧ 发 X                   启动闭环
⑨ 发 O 观察角度           应在 ±0.5° 内
```

改目标：`T,0,500` = +5°，`T,0,-500` = −5°

---

## 七、为什么这组增益有效

```
kp=5.0  kd=0.8  ki=0.08
```

- **不能再高**：kp=8~12 时静态出现 ±1.5° 极限环（舵机死区 + 回差引起）
- **不能再低**：kp=2 时静态极稳（0.05°）但阶跃误差达 4.85°
- kp=5 是静态 0.5° 与阶跃误差 1° 的平衡点
