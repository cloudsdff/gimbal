# 接线清单（任务02 云台 / 任务04 预留）

> 打印出来对着插，插一根划一根。
> 电压用万用表确认过再上电 —— 这套东西今天坏在一块 MPU6050 上，就是供电/接触问题。

## 二、电源部分（先接这一段）

| 从 | 到 | 线 | 说明 |
|---|---|---|---|
| USB 5V | 蓝药丸 5V 引脚 | 红 | 给板子供电 |
| USB GND | 蓝药丸 GND | 黑 | **必须共地** |
| DCP3512 IN+ | 5V（USB 或外部） | 红 | 舵机电源输入 |
| DCP3512 IN− | 公共 GND | 黑 | |
| DCP3512 OUT+（调到 5.0 V） | 舵机 VCC（两根橙/红） | 红 | 先把输出调到 5.0 V 再接线 |
| DCP3512 OUT− | 公共 GND | 黑 | |

> ⚠️ **所有 GND 必须接到同一个点**（板子 GND、DCP3512 GND、舵机 GND、MPU GND）。
> 这是今天 I2C 反复掉线的主要怀疑点之一。

## 三、MPU6050（I2C1）

| MPU 引脚 | 接到 | 线色建议 | 检查点 |
|---|---|---|---|
| VCC | 蓝药丸 **3.3V** | 红 | ⚠️ 不要接 5V，也不要接 DCP3512 的 3.3V（实测那一路不可靠） |
| GND | 公共 GND | 黑 | 与板子 GND 直连 |
| SCL | **PB6** | 黄 | 线长 ≤10 cm，远离舵机线 |
| SDA | **PB7** | 绿 | 同上 |
| XDA / XCL / AD0 / INT | 不接 | — | AD0 悬空时地址可能是 0x69 |

**上电后自检**：串口发 `I` 应打印 `i2c device found at 0x68`；发 `O` 看角度。

## 五、BLE 模块（USART2）

| BLE 引脚 | 接到 | 说明 |
|---|---|---|
| VCC | 3.3V（或 5V，看模块丝印） | |
| GND | 公共 GND | |
| TXD | **PA3**（USART2_RX） | 交叉：模块 TX → 板子 RX |

## 七、上电前检查（逐条打勾）

```
□ 万用表量 DCP3512 输出 = 5.0 V（±0.1）
□ 万用表量 MPU VCC-GND = 3.2~3.4 V
□ 所有 GND 用蜂鸣档量过：板子 / DCP3512 / 舵机 / MPU 之间都通
□ MPU 的 SCL 在 PB6、SDA 在 PB7（不要接反）
□ 舵机信号线在 PA6 / PA7（不要插到 5V 排针上）
□ BLE 的 TX 接 PA3、RX 接 PA2（交叉）
□ 没有任何裸线碰到相邻排针
```

## 八、上电后的自检顺序

| 步骤 | 发什么 | 期望 |
|---|---|---|
| 1 | 看启动日志 | `WHO_AM_I=0x68`、`pwm: TIM3 ... ready` |
| 2 | `I` | `i2c device found at 0x68` |
| 3 | `O` | `angle: yaw=.. pitch=.. roll=..` |
| 4 | `P,1500,1500` | 两台舵机回中位 |
| 5 | `P,1500,1800` | 上层平台抬起，`pitch` 变大 |
| 6 | `Q` | 角度帧停止，屏幕安静 |
| 7 | `T,0,500` | `cmd target: yaw=0.00 pitch=5.00` |
| 8 | `X` | `cmd resume: gimbal enabled` |

## 九、常见故障对照（都是今天踩过的）

| 现象 | 最可能原因 | 处理 |
|---|---|---|
| `probe failed (NoAck)` | MPU 没供电 / 线断 | 量 VCC；换杜邦线 |
| `raw=0,0,0` 或 `raw=-1,-1,-1` | 芯片锁死 | 拔 MPU 的 VCC 3 秒 |
| 采样率掉到十几 Hz | I2C 总线被打挂 | 换短线；确认共地 |
| 舵机抖动/回中不到位 | 舵机供电不足 | 用 DCP3512 独立供电 |
| 串口无输出 | CH340 未识别 | 设备管理器看 COM 口 |
| 角度乱跳 | MPU 松动 | 重新插紧 4 根线 |
